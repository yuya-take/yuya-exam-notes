# Flashcards

暗記カードを作り、Anki に取り込める CSV に追記する。ディレクトリ構成は CLAUDE.md に従う。

## Step 1: 集める

資格の決め方は `/study` と同じ。引数でドメインかトピックが指定されていれば、そこだけを対象にする。
- `<exam>/notes/` の各ノートの「ひとことで」「試験での見分け方」（○×の表）
- `<exam>/mistakes.md` の、卒業していない問題の論点
- 既にある `<exam>/flashcards.csv`（重複を避けるため）

## Step 2: カードを作る

- 1枚に1つの論点にする。表は問い、裏は答えと理由（1〜2文）
- 「〜とは何か」より、「〜のとき、どれを選ぶか」の形を多くする
- 表が既存のカードとほぼ同じものは作らない
- 根拠は、ノートの内容に限る。ノートに無いことはカードにしない
- 機微情報（CLAUDE.md の「機微情報」）を入れない

## Step 3: CSV に追記する

ファイルが無ければ、次の行から始める。Anki が読む設定の行。

```
#separator:Semicolon
#html:false
#columns:表;裏;タグ
#tags column:3
```

1枚1行で追記する。
- 項目の中に `;` や改行を含むときは、項目全体を `"` で囲む。`"` は `""` にする
- タグは `<exam>::d<ドメイン番号>` と、間違えた論点なら `<exam>::mistake`。複数のタグは空白で区切る

```
"エージェントの処理の流れを固定したいときは？";"ワークフロー（プロンプトチェーンなど）を使う。分岐が決まっているならエージェントは不要";ccaf::d1
```

## Step 4: コミットと報告

1. `docs(<exam>): 暗記カードを追加` でコミットする
2. チャットに次を書く
   - 追加した枚数と、全体の枚数
   - Anki への取り込み方: 「ファイル → 読み込む」で `flashcards.csv` を選ぶ。同じファイルを読み直すと、表が同じカードは更新される
