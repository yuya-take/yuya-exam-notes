# yuya-exam-notes

資格試験の学習ノート。

| 資格 | ノート |
|---|---|
| Claude Certified Architect – Foundations | [ccaf/](ccaf/README.md) |

## スキル

| コマンド | すること |
|---|---|
| `/exam-add <資格名> [受験予定日]` | 公式の試験ガイドを調べて、新しい資格のディレクトリ（概要・ドメイン・チェックリスト・学習プラン）を作る |
| `/exam-update [資格 or all]` | 公式情報（試験ガイドの版・形式・比重・出題項目・改訂予定）の変更を調べ、承認したものを反映する |
| `/study <トピック or ドメイン番号>` | 公式ドキュメントで調べてノートにまとめ、チェックリストに紐付ける |
| `/quiz [ドメイン番号 or トピック] [問題数]` | 本番形式の4択問題を1問ずつ出して採点・記録する |
| `/quiz review` | 間違えた問題を、復習日が来たものから出し直す（1→3→7→14日） |
| `/progress` | 進み具合・推定得点率・復習待ちを集計して、次にやることを示す |
| `/orchestrate <目標>` | このセッションを管理者にして、作業を1件ずつ作業セッションに任せる。成果物は別のエージェントが事実を確認してから統合する |
| `/secret-check [--staged or --range A..B]` | コミット・PR の前に、キー・個人情報・受験者 ID・本番問題の再現などが含まれていないかを調べる（`git commit` / `git push` ではフックでも自動で検査） |
| `/pr [タイトル]` | `/secret-check` を通してから push し、main 向けの PR を作る・更新する |
| `/model-tune [モデル名]` | 新しい Claude モデルや Claude Code の仕様変更に合わせて、スキルを公式ドキュメントと突き合わせて調整する |
